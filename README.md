# Pratham Shah 3D Portfolio

A Vite, React, TypeScript, Three.js, GSAP, and React Three Fiber portfolio inspired by the 3D portfolio reference project, customized from Pratham Shah's resume.

The hero uses Pratham's transparent avatar image at `public/images/pratham-avatar-cutout.png`, so it does not depend on the reference project's copied character model.

## Quick Start

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
```

The production build is generated in `dist/`.
